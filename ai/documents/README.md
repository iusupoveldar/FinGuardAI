# Synthetic RAG corpus

These documents describe the fictional **Eldar Northstar Community Bank** and are
intended only as development fixtures for FinGuardAI retrieval and investigation
workflows. They are not legal guidance or real company policy.

Each Markdown file starts with a small YAML metadata block that can be preserved
when the documents are chunked and embedded. A future ingestion job can use
`document_id`, `title`, `category`, `effective_date`, and `version` as retrieval
metadata.
